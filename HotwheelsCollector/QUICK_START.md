# ⚡ INICIO RÁPIDO

## 1️⃣ Ejecutar Setup Automático

```bash
cd HotwheelsCollector
.\setup.bat          # Windows
# O en Mac/Linux:
bash setup.sh
```

**Espera a que se complete (2-5 minutos)**

## 2️⃣ Correr la Aplicación

```bash
dotnet run
```

## 3️⃣ Abrir en Navegador

```
http://localhost:5034
```

## 4️⃣ ¡Listo!

✅ Regístrate
✅ Añade colecciones
✅ ¡Disfruta!
